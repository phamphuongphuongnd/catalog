Studio catalog

Static JSON data for Mobile App Studio apps, updated weekly by GitHub Actions.

  • subnest/v1/meta.json — version + sha256
  • subnest/v1/services.min.json — Subnest service catalog (app)
  • subnest/v1/services.json — same, readable, with maintainer notes
  • schema/subnest-v4.schema.json — JSON Schema

Service names and logos belong to their owners. Prices are for reference only. Source: github.com/phamphuongphuongnd/catalog
